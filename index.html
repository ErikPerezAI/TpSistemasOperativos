Explorando los Sistemas Operativos

Descubre cómo funcionan los sistemas que hacen posible la interacción entre el hardware y el software

¿Qué es un Sistema Operativo?

Un Sistema Operativo (SO) es el software fundamental que gestiona el hardware de una computadora y proporciona servicios esenciales para los programas de aplicación.

Intermediario

Actúa como puente entre el hardware y las aplicaciones

Gestor de Recursos

Administra CPU, memoria, almacenamiento y periféricos

Coordinador

Ejecuta múltiples programas simultáneamente

Protector

Garantiza seguridad y aislamiento entre procesos

Funciones Principales

Gestión de Procesos: Controla la creación, ejecución y terminación de procesos, asignando tiempo de CPU de manera eficiente.

Gestión de Memoria: Administra la memoria RAM, asignándola dinámicamente a los procesos que la necesitan y liberándola cuando ya no es necesaria.

Gestión de Archivos: Organiza, almacena y recupera información en dispositivos de almacenamiento mediante sistemas de archivos.

Gestión de E/S: Coordina la comunicación entre el sistema y los dispositivos de entrada/salida como teclados, monitores, impresoras, etc.

Tipos de Sistemas Operativos

Los sistemas operativos se clasifican según su propósito, arquitectura y casos de uso específicos

Sistemas de Escritorio

Windows, macOS, Linux Ubuntu

Diseñados para uso personal en computadoras de escritorio y portátiles. Ofrecen interfaces gráficas amigables y soporte para una amplia variedad de aplicaciones.

Sistemas de Servidor

Windows Server, Linux Server, Unix

Optimizados para gestionar múltiples usuarios simultáneos, manejar grandes volúmenes de datos y proporcionar servicios de red confiables y seguros.

Sistemas Móviles

Android, iOS, HarmonyOS

Especialmente diseñados para dispositivos móviles como smartphones y tablets. Priorizan eficiencia energética, pantallas táctiles y conectividad inalámbrica.

Sistemas en Tiempo Real

QNX, VxWorks, FreeRTOS

Utilizados en aplicaciones críticas donde el tiempo de respuesta es crucial, como sistemas médicos, control industrial, automóviles y aeronáutica.

Otras Clasificaciones

Por Número de Usuarios

  • Monousuario: Permite un usuario a la vez (MS-DOS)
  • Multiusuario: Múltiples usuarios simultáneos (Linux, Unix)

Por Número de Tareas

  • Monotarea: Ejecuta un programa a la vez
  • Multitarea: Ejecuta múltiples programas simultáneamente

Componentes Fundamentales

Kernel (Núcleo)

El corazón del sistema operativo

El kernel es el componente central del sistema operativo. Es el software que tiene control completo sobre todo en el sistema. Actúa como intermediario entre el hardware y el software de aplicación, gestionando recursos del sistema y proporcionando servicios esenciales.

Kernel Monolítico

Todo el SO corre en modo kernel. Mayor rendimiento pero menos modular. Ejemplo: Linux

Microkernel

Solo funciones básicas en kernel. Más estable y seguro. Ejemplo: Minix, QNX

Kernel Híbrido

Combina ambos enfoques. Balance entre rendimiento y modularidad. Ejemplo: Windows NT

Firmware

Software de bajo nivel grabado en chips de memoria no volátil. Proporciona control básico del hardware y permite la comunicación inicial entre componentes físicos.

  • Reside en ROM, EEPROM o memoria flash
  • Ejecuta instrucciones al encender el dispositivo
  • Ejemplos: BIOS, UEFI, firmware de routers

BIOS y UEFI

BIOS (Basic Input/Output System)

Firmware tradicional que inicializa el hardware durante el arranque y carga el sistema operativo. Limitado a discos de 2TB y modo 16 bits.

UEFI (Unified Extensible Firmware Interface)

Sucesor moderno de BIOS. Soporta discos mayores a 2TB, arranque más rápido, interfaz gráfica, mejor seguridad con Secure Boot y modo 32/64 bits.

Partición de Disco

Una partición es una división lógica del espacio de almacenamiento en un disco duro o SSD. Permite instalar múltiples sistemas operativos, organizar datos y mejorar el rendimiento.

Partición Primaria

Puede contener un sistema operativo booteable. Máximo 4 en MBR

Partición Extendida

Contenedor para particiones lógicas. Permite superar el límite de 4 particiones

Partición Lógica

Subdivisiones dentro de una partición extendida

Gestión del Sistema

El sistema operativo administra múltiples aspectos críticos para el funcionamiento óptimo del sistema

Gestión de Procesos

Control de la ejecución de programas

  • Creación, suspensión y terminación de procesos
  • Planificación de CPU (scheduling): FCFS, Round Robin, SJF
  • Sincronización y comunicación entre procesos
  • Manejo de hilos (threads) y multiprocesamiento

Gestión de Memoria

Administración eficiente de RAM

  • Asignación y liberación de memoria a procesos
  • Memoria virtual y paginación
  • Segmentación de memoria
  • Prevención de fragmentación

Gestión de E/S

Coordinación de dispositivos

  • Drivers de dispositivos
  • Buffering y spooling
  • Caching de datos
  • Manejo de interrupciones

Gestión de Archivos

Organización de información

  • Sistemas de archivos: FAT, NTFS, ext4, APFS
  • Operaciones: crear, leer, escribir, eliminar
  • Control de acceso y permisos
  • Directorios y rutas

Seguridad y Protección

Salvaguardar datos y recursos

  • Autenticación de usuarios
  • Control de acceso (ACL)
  • Cifrado de datos
  • Protección contra malware y ataques

Comunicaciones

Manejo de redes

  • Protocolos TCP/IP
  • Sockets y APIs de red
  • Servicios de red: DNS, DHCP
  • Seguridad de red: firewalls

Gestión de Recursos

Optimización del uso de recursos

  • Monitoreo de rendimiento
  • Balanceo de carga
  • Gestión de energía
  • Priorización de tareas

Interfaz con el Usuario

Medios de interacción

  • GUI (Interfaz Gráfica): Windows, macOS, GNOME, KDE
  • CLI (Línea de Comandos): Bash, PowerShell, CMD
  • Accesibilidad y personalización
  • Gestión de ventanas y escritorios

Servicios del Sistema Operativo

Los servicios son funcionalidades que el SO proporciona a las aplicaciones y usuarios para facilitar el uso eficiente del hardware y simplificar el desarrollo de software.

Ejecución de Programas: Carga y ejecución de aplicaciones
Operaciones de E/S: Acceso a dispositivos periféricos
Manipulación de Archivos: Lectura, escritura y gestión
Detección de Errores: Monitoreo y manejo de fallos
Comunicaciones: Intercambio de datos entre procesos
Asignación de Recursos: Distribución equitativa
Contabilidad: Registro de uso de recursos
Protección y Seguridad: Acceso controlado a recursos
